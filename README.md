## 🚀 PROYECTO DESTACADO

### 🚗 Nothingan-Prisa
**Sistema de Gestión de Alquiler de Vehículos**

Aplicación web de alquiler de vehículos desarrollada en equipo aplicando una arquitectura MVC y buenas prácticas de desarrollo.

- **Características principales:**
  - Gestión integral de flotas de vehículos y usuarios.
  - Persistencia de datos optimizada con **Spring Data JPA**.
  - Interfaz dinámica y fluida con **Thymeleaf**.
  - Trazabilidad y sistema de registros (logs) con **Logback**.
  - Panel de administración y documentación técnica detallada.
